# 📱 Social Media Trend Analyzer

A Python-based **Social Media Trend Analyzer** that analyzes social media text data to identify trending topics, popular keywords, and sentiment patterns. The project uses **Natural Language Processing (NLP)** and **Machine Learning** techniques to extract meaningful insights from social media content.

## 🚀 Project Overview

Social media generates a huge amount of textual data every day. Understanding this data can help identify what topics, keywords, and sentiments are currently gaining attention.

The **Social Media Trend Analyzer** provides an interactive interface where users can upload or analyze social media data and explore trends through keyword analysis, sentiment classification, and visualizations.

## ✨ Features

* 📊 Interactive data analysis dashboard
* 🔍 Keyword and trend extraction
* 😊 Sentiment analysis
* 📈 Data visualization using charts
* 🧹 Text preprocessing and cleaning
* 🤖 Machine Learning-based sentiment classification
* ☁️ Word-frequency analysis
* 📁 CSV dataset support
* ⚡ Built with Streamlit for an interactive web interface

## 🧠 NLP & Machine Learning

The project uses **Natural Language Processing** techniques to process social media text.

### Text Preprocessing

The text data is cleaned using techniques such as:

1. Converting text to lowercase
2. Removing unnecessary characters
3. Removing special symbols
4. Cleaning unwanted spaces
5. Extracting meaningful words and keywords

### TF-IDF

**TF-IDF (Term Frequency–Inverse Document Frequency)** is used to convert text into numerical features that can be processed by the machine-learning model.

### Logistic Regression

A **Logistic Regression** classifier is used for sentiment classification. Based on the processed text, the model can classify content into sentiment categories according to the dataset used.

## 📊 Analysis

The analyzer can provide insights such as:

* Most frequently used keywords
* Trending words and topics
* Positive, negative, and neutral sentiment distribution
* Frequency of social media content
* Text-based patterns
* Sentiment-related visualizations
